1) script.google.com > مشروعك: لكل ملف امسح كل المحتوى ثم الصق الجديد:
   Code (سكربت)  <- Code.txt أو Code.gs
   index (HTML)  <- index.txt أو index.html
   intake (HTML) <- intake.txt أو intake.html
2) تأكد أن index ينتهي بـ </script></body></html> (Ctrl+End).
3) شغّل الدالة setup مرة واحدة ووافق على الصلاحيات.
4) Deploy > Manage deployments > القلم > Version: New version > Deploy
   (Execute as: Me | Who has access: Anyone).
5) افتح الرابط ثم سجّل الدخول: admin / admin (تكتبهما بنفسك).
روابط: التسجيل = الرابط?intake=1 | المتابعة = الرابط?watch=1
